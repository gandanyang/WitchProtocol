## 二、BUG-008~012 修复复核

### BUG-008 · 孤儿弹访问已释放池 — 通过（含残留备注）
- **修复形态**：子弹由物理体 `Area2D` 改为轻量 `Node2D`（去物理、自写距离碰撞），`Pool.Release` 只操作 C# 托管字段（`_active`/`_pool`）与传入的存活子弹，**不触碰池自身 native 节点**——池释放后再调 `Release` 不会抛「访问已释放实例」。
- **验证**：`ProbeM1OrphanBullet`（池 Free 后 `RecycleSelf` 不抛异常）PASS；Main.B 对敌弹遍历带 `!Visible` 跳过已回收节点。
- **残留备注（低）**：孤儿弹（池已随敌人销毁、节点残留在 `EnemyBullets` 层）不会崩溃，但**波次内不主动清**，需到 `SetupStage` 重开时统一 `QueueFree`。建议后续在 `wave_cleared` 时顺带清一次，减少波次内幽灵弹存量。

### BUG-009 · 战败演出后相机 Zoom 未复位 — 通过
- **修复形态**：新增 `FeedbackSystem.ResetZoom()`（清 `_zoomT` + `Camera.Zoom = One`）；`DeathSequence.Finish()` 在演出结束、结算出现前调用。
- **验证**：代码确认复位路径存在，`feedback` 探针 PASS。

### BUG-010 · 战败重开后自机 Position/Rotation/IsDying 未复位 — 通过
- **修复形态**：`RestoreForStage()` 现重置 `_velocity/_fallVelocity/IsDying/Rotation/Modulate/_fireTimer/_hitFlashTimer`；`DeathSequence.Finish()` 额外把 `Position` 复位到出生点 `PlayfieldSize/2+(0,120)`（与 Main.SetupStage 一致，幂等）。
- **验证**：`deathfall` 探针 PASS；代码确认链路闭合。

### BUG-011 · BossConfig.tres snake_case 失效 + 探针无区分度 — 通过
- **修复形态**：`BossConfig.tres` 键名全部改为 PascalCase（`MaxHp=60/MoveSpeed=40/BulletSpeed=160/RingCount=16/RingInterval=1.6/SpiralCount=8/SpiralInterval=0.5/AimedInterval=2.2`）。
- **验证**：`ProbeBossConfig` 加哨兵 `cfg.MaxHp == 50 → false`（默认值空转即败）、`ProbeEnemyConfig` 加哨兵 `cfg.MaxHp == 3 → false`；`boss_config`/`enemy_config` 探针 PASS，现具备真区分度。

### BUG-012 · TimeScale 残留 / 接触伤害未落地 / 探针空转 — 通过
- **修复形态**：`DeathSequence.Finish()` 显式 `Engine.TimeScale = 1f`；敌人接触伤害落地——`Enemy.ContactPlayer()` 派发 `player_hit` + 自身 `QueueFree`，由 Main.C 距离检测触发；哨兵纪律同上。
- **验证**：`m1_enemy_contact` 探针 PASS，`deathfall`/`feedback` PASS。

## 五、注意事项 / 小建议（非阻塞）

1. **BUG-008 残留（低，已实施）**：波次内击杀敌人产生的孤儿弹不主动清、留到重开清的问题——已落地 `Main.ClearEnemyBullets()`，在 `Main.OnWorldEvent` 的 `wave_cleared` 处清空 `EnemyBullets` 孤儿弹（并作废 B 段碰撞缓存快照），`SetupStage` 复用同一方法。验证：build 0 错误 0 警告 + 20/20 探针全绿。
2. **探针注释与实况不符（低/文档）**：`ProbeM1OrphanBullet` 注释写「走 QueueFree 兜底」，实况是走 `Release` 静默回收（因 Release 只操作托管字段不崩）。建议修正注释，避免误导。
3. **5000 弹档离预算很近（提示）**：建议把渲染侧 `StressTest.tscn` 跑一遍确认真实帧率，再决定是否要把默认弹量上限压低或做合批调优。
4. **其余**：`Enemy/Boss/TakeDamage` 均有 `_hp <= 0` 防同帧重复结算守卫；`Main` 对 `_over` 守卫与结算暂停路径正确；`DeathSequence` 复位路径幂等。未发现新的 P0/P1 缺陷。
