# AI 开发护栏（强制红线）

> 所有 AI 在魔女协议项目上开工前必读。违反红线 = 立刻停下重做。

## 一、测试后门纪律（硬性）

DevTestHub 是开发验证工具，**发布构建必须彻底隐藏**。

1. **探针/种子只在 DEV / DEBUG 生效**：不得影响正常游戏流程，不得被正常玩法触发。
2. **使用现有系统预置状态**：测试种子必须用现有存档/事件系统（SaveSystem / EventBus）模拟真实玩家状态，**禁止**直接改内存指针 / 改私有字段 / 绕过正常流程。
3. **无存档污染**：探针是只读的；测试种子结束必须还原状态（Reset 归位），不得给正式玩家留下脏数据。
4. **构建隔离**：发布/导出构建里，测试入口必须不可达（当前 DevTestHub 探针仅在 headless + 显式 --probes 参数时执行，天然隔离；新增入口必须保持同等级隔离）。

## 二、存档红线（硬性）

- `SaveSystem.SaveVersion` 是存档格式契约。**只有破坏性结构变更才递增**。
- 新增字段必须「可选 + 默认值兜底」，**严禁仅因加字段就升版本号**。
- 清档 / 迁移前**必须先备份**旧档到 `user://save_backup_{版本}.json`（`SaveSystem.Reset()` 已实现）。
- 读取任何字段都走 `SaveSystem.Get(key, 默认值)`，**拒绝在业务代码里出现 null 断言**。
- 详见 `docs/dev/SaveSystem.md`。

## 三、开工三问（每个任务开始前）

1. **这次改动会不会破坏已验证的 5 个探针？**（会 → 先说明理由，改完必须全绿）
2. **这个功能是「必要的」还是「看起来酷」？**（后者 → 降级或砍掉）
3. **改动后怎么验证？**（没有验证路径的改动不要提）

## 四、弹幕性能纪律

- 弹幕 hotpath（每帧几千次命中）**不走事件总线**，用对象池内直连。
- 子弹一律从 `BulletPool` 获取，**禁止高频 new**。
- 相机 / 出屏裁剪 / 对象池清理以 `GameManager.PlayfieldSize` 为准。

## 五、数据驱动纪律

- 角色 / 数值 / 弹幕配置用 `.tres` 资源，**禁止在代码里硬编码魔法数值**（常量表除外）。
- 改 `.tres` 前先确认资源引用关系，避免破坏已有场景。

## 六、环境与工具纪律

- **沙箱 user:// 重定向**：TRAE 沙箱下跑 Godot 用 `tools/run_tests.ps1`（已把 APPDATA 重定向到 `.godot/userhome`）。手动裸跑 Godot 写 `user://` 会被沙箱拦截，属预期行为。
- **PowerShell 编码**：`tools/*.ps1` 必须保持 UTF-8 with BOM，否则 Windows PowerShell 5.1 会把中文注释解析成乱码报错。
- **本机路径不写死入库**：Godot 路径在 `tools/*.ps1` 顶部 `$GodotRoot`，机器不同改这里即可。
