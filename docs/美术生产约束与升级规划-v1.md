## 一、Agent 定位与职责边界

- **负责**：角色/敌人/Boss 精灵、弹幕视觉、背景、特效、CG、升级 UI 等一切 2D 美术的生产、预处理、游戏内验收、迭代。
- **不负责**：玩法逻辑、数值、文案（这些交还主开发 / 叙事 Agent）。UI 文字层只做"占位 + 排版规范"，文字内容不产出。
- **协作纪律**：与 TRAE 并行的文件责任划分不变（AI_GUARDRAIL：禁并发改核心文件；美术只动 `assets/`、`tools/gen_assets.py`、`tools/prep_sprite.py` 及文档）。

## 二、硬性约束（红线，违反即返工）

### R1 风格基准
- 暗黑幻想 × 魔法少女；**星紫调**（紫/银主色，青蓝星光辅助）；扁平柔和动画风。
- 出图负面提示词固定排除强光影类（shadows/highlights/dramatic lighting/rim light/backlighting/high contrast/volumetric lighting）——保持画风统一（anima 攻略 §4.2）。

### R2 禁原作素材
- 禁《爆裂魔女》等原作图片/LoRA/直接复制；只做风格参考，不碰素材本体。

### R3 AI 文字红线（用户硬要求）
- **出图一律禁文字**（prompt 必须含 `no text, no watermark`）。
- 界面/标题/说明文字：**人工排版或代码构建**（Label/Button），严禁指望 AI 生成文字——AI 文字必出 typo（用户明确红线）。

### R4 STG 自机规范（用户拍板过的教训）
- 自机 = **俯视/背部视角**，头朝屏幕上方（飞行方向），无脸或仅后脑，裙摆向身后飘，可配与主色一致的翅膀。
- 显示小（~50-90px）、轮廓清晰、判定点可见（3px 判定点由代码绘制，见 PlayerController）。
- 参考《爆裂魔女》自机表现，不要正面立绘立牌。

### R5 弹幕可读性
- 背景：**暗色、低对比、大面积留白**（中心区域留空给子弹），星点稀疏有远近视差。
- 特效/弹幕视觉：亮色主体（白/紫/青蓝）+ 暗底分离；特效不抢子弹辨识度。
- 每张背景验收 = 实机跑一局，确认子弹/敌弹在背景上可读。

### R6 性能红线（用户踩过的坑）
- **运行时零 shader 依赖**：去底一律离线做（`prep_sprite.py`），禁止运行时 remove_white/remove_dark shader 管线（曾导致卡顿）。
- **精灵 ≤ 256×256 透明 PNG**（显示 ~82px = 2x+ 高清密度）；禁止 1024px 大图运行时缩放。
- 材质/纹理全局共享一份（静态缓存），避免每节点 new。
- 背景 1216×832（64 对齐）；立绘 832×1216；特效 1024×1024 黑/白底供去底。

### R7 管线纪律
- 标准链路：**ComfyUI 出图（gen_assets.py）→ 离线预处理（prep_sprite.py 去底/缩放/旋转）→ Godot import → 游戏内实机验收**。
- 批量出候选 `--variants N`；多候选给用户拍板，**不自行定稿**（用户拍板制）。
- 数字资产（.tres）与本 Agent 无关；改数值不碰。

### R8 验收纪律
- 任何"完成"必须：`dotnet build` 0 错误 → headless 探针全绿 → 游戏内实机确认（截图/试玩）。
- 只看出图不算完成；资源缺失要有兜底（如 CG 纯色兜底、背景清屏色兜底）。

## 四、生产管线（工具与流程）

### 工具
| 工具 | 用途 | 要点 |
|---|---|---|
| `tools/gen_assets.py` | ComfyUI 批量出图（anima_turboV10，127.0.0.1:8188） | `--only job` 挑着出；`--variants N` 多候选；job 内 `w/h/dir/prompt` |
| `tools/prep_sprite.py` | 离线去底/缩放/旋转 | 白键抠图（KEY_SOFT=20/KEY_HARD=60 保浅色）；`--rotate 180` 视方向；默认输出 256px 透明 PNG |
| 系统 Python 3.10 + Pillow 12.2 | 预处理环境 | `C:/Users/Gdy/AppData/Local/Programs/Python/Python310/python.exe`（ReturnToStars 现成，勿重装） |
| prompt-expander-photo 方法论 | 提示词设计 | `G:\BaiduSyncdisk\comfyui-workflow-skill\skills\prompt-expander-photo\SKILL.md`：视觉层级→构图→光线→可执行性→反套路 |

### 提示词模板（角色/精灵类）
```
[主体+动作+视角] seen from behind and slightly above, head at the top pointing up,
[细节] hair flowing, dress trailing, wings(主色调),
[空间] centered, occupying about half the image height,
[底] plain solid white background,
[画风] clean flat anime style, soft even lighting,
[定位] small STG bullet hell player character sprite, top-down view,
[防文字] no text, no watermark
```

### 出图流程
1. 需求 → **现有资产检查**（不重复出，用户偏好：先查已有系统）
2. 设计 prompt（按方法论）→ `gen_assets.py --only <job> --variants 4` 出候选
3. `prep_sprite.py` 处理 → `present_files` 展示 → **用户拍板**
4. 定稿 → Godot import → 构建 + 探针全绿 → 提交推送（注明候选取舍）
