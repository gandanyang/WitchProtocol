# 《魔女弹幕计划》设计规范 v0.1

> 状态：**设计基准**（2026-08-19 归档）
> 项目：《Witch Protocol：魔女协议》· MVP 设计依据
> 参考对象：《爆裂魔女》（仅作设计样本，非素材来源）
> 与《MVP 开发计划 v0.1》的关系：美术/角色资产包/美术优先级/视觉统一规则/升级列表以此文档为准；战斗流程与里程碑以 MVP 开发计划为准。

---

## 1. 项目定位

> **二次元魔女 × 弹幕射击 × 黑暗幻想 × 王道热血**

目标不是"飞机小游戏"，而是以高完成度 MVP 为起点，扩展成具有商业二次元游戏质感的独立作品。

核心体验：

> 选择魔女 → 空战割草 → 获得强化 → 构筑弹幕 → 挑战 Boss → 破解机制 → 被 Boss 击败 → 结算 → 产生再次挑战欲望

技术方向：引擎 Godot 4.x · 语言 C# · 美术 ComfyUI 为主 · 音频 AI 辅助 + 后期制作 · 首发 PC（后续视情况移动端）

## 2. 参考对象《爆裂魔女》

不是素材来源，而是**成熟商业作品的设计样本**。重点参考四个方面：

### 2.1 魔女角色与世界观绑定

角色 = 人物设定 + 服装 + 武器 + 魔法 + 弹幕 + 技能 + 剧情，构成**完整链条**：

> 角色主题 → 魔法主题 → 弹幕主题 → 技能演出 → Boss 互动

避免：立绘一个风格、战斗弹幕另一套风格。

### 2.2 弹幕不是纯数值，而是视觉语言

每个魔女必须有**辨识度极高的攻击模式**。检验标准：

> "把 UI、角色头像全部隐藏，只看弹幕，玩家能不能认出她？"

| 魔女 | 核心魔法 | 弹幕语言 |
|---|---|---|
| 黎歌 | 星辉 | 星轨、追踪、穿透 |
| 绯月 | 血月 | 血刃、近战、狂暴 |
| 艾琳 | 召唤 | 魔法使魔、自动攻击 |
| 诺娅 | 冰晶 | 冻结、减速、区域控制 |

### 2.3 Boss 是"战斗演出"

不是加血量，而是**舞台表演**：阶段变化 / 音乐变化 / 弹幕变化 / 场景变化 / 机制变化 / 技能演出 / 最终必杀。让玩家感觉"我不是在打一个血条，我是在经历一场 Boss 战"。

### 2.4 暗黑幻想视觉体系

参考其视觉启发，不直接复制：哥特幻想 / 魔法少女 / 暗色背景 / 高亮魔法 / 巨型魔法阵 / 华丽服装 / 强烈光影 / 舞台化 Boss 演出。

**视觉关键词：暗黑幻想 × 魔法少女 × 空战弹幕 × 史诗舞台**

## 3. 参考原则（红线）

**可以参考**：美术风格 / 色彩关系 / 构图思路 / UI 信息层级 / Boss 演出逻辑 / 弹幕设计思路 / 角色与战斗绑定方式 / 商业二次元游戏视觉表达

**不直接使用**：原作角色立绘 / 原始精灵素材 / 原始 UI / 原始背景 / 原始 Boss / 原始特效 / 原始图标 / 原始音频 / 拆包资源 / **用原作资源训练 LoRA**

所有美术资源：**重新设计、重新生成、重新组合**。《爆裂魔女》是"参考案例"，不是"素材库"。

## 4. ComfyUI 美术生产原则

目标：**建立统一的 AI 美术生产管线**，不是"AI 什么都能画"。

### 4.1 角色资源（每魔女一个资产包）

```
Witch_X
├── CharacterSheet
├── Portrait
├── FullBody
├── BattleSprite
├── SkillPose
├── UltimatePose
├── DamagePose
└── StoryCG
```

从立绘起确定：发色 / 眼睛 / 发型 / 服装 / 饰品 / 武器 / 魔法主题 / 主色 / 辅助色 / 象征物

### 4.2 Boss 资源

Boss 立绘 / 战斗模型精灵 / Boss 头像 / 技能演出图 / 魔法阵 / 阶段特效 / 最终技能演出 / 背景素材

### 4.3 特效资源（统一特效词库）

```
Magic Circle / Spell Ring / Arcane Energy / Gothic Ornament /
Luminous Particle / Star Fragment / Blood Moon / Ice Crystal /
Lightning Arc / Void Energy
```

特效必须服从角色主题。不能所有角色都用"一坨蓝紫色发光特效"。

## 5-6. 黎歌战斗体系（MVP 唯一完整魔女）

定位：**星辉魔法 / 万能型 / 中距离**。目标是把一个魔女做到"完全体"。

**普通攻击·星辉魔弹**：自动连续射击，初始直线星弹/中等射速/中等范围，随升级演化：

```
基础星弹 → 多方向 → 穿透 → 追踪 → 星轨 → 星环 → 组合弹幕
```

**主动技能·星轨展开**：提升攻击 + 生成环绕星弹 + 增加追踪能力 + 短时间强化状态。目标："技能一开，整个屏幕开始变漂亮了。"

**Bomb·星辰坠落**：巨大魔法阵展开 + 星辉陨落，大范围清屏 / 伤害 Boss / 短时间安全空间。视觉目标：**MVP 第一个"截图级瞬间"**。

## 7. 割草部分（一局前半段 5-7 分钟）

敌人不追求数量多，强调**不同攻击逻辑**：基础飞行怪 / 自爆怪（逼移动）/ 狙击怪（锁定线预警）/ 弹幕怪（场面压力）/ 坦克怪（高血量，让火力升级有价值）/ 精英怪（高威胁、特殊攻击模式）

## 8. 升级系统（MVP 暂定 12 种）

掉落星之残片 → 经验 → LEVEL UP → 三选一：

1. 火力强化 2. 速射 3. 穿透 4. 追踪 5. 星环 6. 爆裂
7. 引力 8. 护盾 9. 星辉余波 10. 主动技能强化 11. Bomb 强化 12. 低 HP 过载

核心不是数值膨胀，而是：**让玩家的弹幕形态越来越夸张**。

## 9. 一局战斗节奏

```
00:00 出击 → Wave1 → Wave2 → Wave3 → Wave4 → 精英怪 → Wave5 → 强化选择 → Boss 登场
```

玩家感受：前期"我在学习游戏" → 中期"我越来越强" → Boss 前"我已经是一台弹幕机器" → Boss"等等，这玩意儿怎么这么难？"

## 10-15. Boss：初代魔女「阿斯特拉」

身份：世界上第一位魔女，曾拯救人类，现已成为灾厄的一部分。非传统反派，理念：**"如果痛苦来自于人类拥有选择，那么只要消除选择，人类就能获得幸福。"**

| 阶段 | 触发 | 内容 |
|---|---|---|
| 审判（P1） | 开场 | 星落（锁定预警→陨石）/ 星之雨（持续小弹幕）/ 十字审判（旋转十字激光）/ 弹幕环（找缺口） |
| 星核机制 | 75% | 4 枚星核，Boss 本体受保护 + 持续回血；打掉星核解除防护 → 第一次告诉玩家"Boss 不能只靠无脑输出" |
| 模仿（P2） | 50% | Boss 复制玩家用过的攻击（星环→巨大星环；追踪弹→敌方追踪弹）→ **镜像关系** |
| 终焉仪式（P3） | 25% | 玩家无法直接攻击；3 个核心限时破坏；失败→提前终焉。无论成败进入最终阶段 |
| 终焉·星界坠落 | 最终 | 停止攻击 → 音乐骤降 → 裂缝扩大 → 巨型法阵 → 大量弹幕 → 巨大星体坠落 → 最终躲避 → 黎歌被击落 |

## 16. MVP 结局（必须被击败，但不是 Game Over）

黎歌"……还不够……" → 镜头拉远 → Boss 漂浮天空 → 裂缝扩大 → 黑屏 → `DEFEATED` + 战斗统计（战斗时间/击败敌人/最高等级/获得星之残片/Boss 阶段）→ **"她还活着。"** → 再次挑战

形成最基本循环：**失败 → 不服 → 再来一次**

## 17. 美术优先级（不平均分配精力）

| 级别 | 内容 |
|---|---|
| S | 黎歌角色设计 / 黎歌战斗表现 / 玩家子弹 / Boss 立绘 / Boss 弹幕 / Boss 最终技能 / 战斗背景 / 击杀受击反馈 |
| A | 普通敌人 / UI / 升级选择 / 魔法阵 / 爆炸特效 |
| B | 复杂剧情 CG / 大量场景 / 非核心 NPC / 大量装饰物 |

判定：**玩家截图的时候，看起来就像一个"正经二次元游戏"。**

## 18. 视觉统一规则

| 项 | 规范 |
|---|---|
| 角色 | 二次元高质量角色设计 |
| 场景 | 暗色幻想背景 |
| 弹幕 | 高亮、清晰、可读 |
| UI | 哥特幻想风 |
| 魔法 | 复杂法阵 + 高亮核心 + 粒子 |
| Boss | 明显高于普通敌人的视觉规格 |

**视觉中心始终明确**，不能"所有东西都在发光，最后什么都看不清"。

## 19. Godot 架构原则

```
Game / Core / Battle(Player,Bullet,Enemy,Boss,Wave) / Witch(WitchData,Weapon,Skill)
    / Progression(Experience,Level,Upgrade) / UI / Content
```

核心原则：**内容数据化，代码系统化**。新增魔女/敌人/Boss/升级不改核心战斗逻辑。

## 20. MVP 完成判定（不是功能数量，是一条完整体验）

进入游戏 → 黎歌出击 → 移动/射击 → 击杀小怪 → 获得经验 → 升级 → 弹幕增强 → 精英怪 → Boss 登场 → P1 → 机制 → P2 → 终焉仪式 → 最终技能 → 玩家死亡 → 结算 → 再次挑战

成功标准：第一次玩的玩家产生 **"这游戏如果继续做下去，好像真的能有点东西。"**

## 21. 后续扩展路线（不立刻堆内容）

V0.1 黎歌+小怪+Boss → V0.2 第二魔女 → V0.3 局外成长 → V0.4 第一章剧情 → V0.5 第二个 Boss → V0.6 完整世界观框架 → V0.7+ 正式游戏

## 22. 最终视觉目标

不追求"像《爆裂魔女》"，追求：

> 如果《爆裂魔女》、东方系弹幕、现代二次元商业游戏和个人 AI 开发结合，会是什么样？

识别度五条：**魔女角色有记忆点 · 弹幕有角色性格 · Boss 有舞台感 · 剧情有黑暗面 · 战斗有王道热血**。美术统一。**AI 只负责提高生产力，而不是决定作品长什么样。**
