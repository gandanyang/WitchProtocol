**为什么现在转**：继续优化架构的边际收益已下降。5000 弹 CPU 24.92ms 超过 16.67ms/60FPS 预算——但那是**极限压力测试**，不是正常战斗目标。不因此立即上 Bullet 全量数据化 / MultiMesh / RenderingServer / Spatial Grid 全套重写。

**合理路径**：交互式 StressTest 看真实体验 → 确定正常战斗 / Boss 战 / 终焉演出的实际弹量预算。

## 二、性能红线分层（替代"5000 弹必须 60FPS"）

| 场景 | 目标 |
|---|---|
| 普通战斗 | 60 FPS |
| 普通 Boss | 60 FPS |
| 高密度 Boss | ≥ 50 FPS |
| 终焉演出 | ≥ 45 FPS |
| 极限 StressTest | ≥ 45 FPS |

5000 弹 = 压力测试红线，**不是正常游戏设计指标**。未来"爆裂魔女式弹幕海"重点是**视觉密度**，不是追求一万颗实际碰撞子弹——与"软保留 + 二次元爽感"方向一致。

## 三、M2 重新定义

**不叫**"M2：经验 + 升级"，**叫**：

> ## M2：割草爽感与养成闭环

验证的不是"系统有没有"，而是：

> **玩家打怪 → 变强 → 弹幕越来越漂亮 → 越来越爽。**

### 核心产品公式（项目级）

> **《魔女协议》 = 弹幕动作 × 轻度割草 × 二次元构筑**

不是"弹幕游戏 + Survivors + 二次元皮肤"。区别：三要素同时存在、互相支撑。

### 防 Survivors 化（三原则，硬性）

1. 玩家永远**主动移动 + 主动躲避 + 主动选择路线**（不做"敌人100只冲过来站着自动杀"）
2. **割草负责爽**、**弹幕负责操作**、**养成负责构筑**
3. 魔女空战 + 弹幕是核心，割草是手段不是目的

## 四、M2 三阶段

### 阶段一：星之残片（磁吸）

```text
敌人死亡 → 掉落星之残片 → 玩家靠近自动磁吸 → 进入玩家 → 经验条增长
```

**不做"走过去捡"**——项目不是硬核 STG，玩家应专注"躲弹幕 + 看魔女表现"，而不是数漏了几个经验球。**磁吸**是硬需求。

### 阶段二：等级提升 + 三选一

经验满 → LEVEL UP → 暂停战斗 → 三选一升级。

**升级不能全数值**，M2 第一版就区分两型：

| 类型 | 示例 | 占比 |
|---|---|---|
| 数值型 | 攻击力 +20% / 射速 +15% / 技能冷却 -10% | 一部分 |
| **行为型**（重点） | 见下 | 更多 |

黎歌行为型升级（弹幕语言变化）：
- **星辉追踪**：普通弹开始轻微追踪敌人
- **星屑爆裂**：击杀敌人后产生小范围星爆
- **星轨**：连续射击后出现旋转星轨
- **星环**：玩家周围出现环绕弹幕
- **残响**：子弹命中后留下短暂星光

核心体验："升级后我会玩出不一样的东西"，不是"数字变大了"。

### 阶段三：敌人分类 + WaveConfig 数据驱动

**M2 只用四类（不做十几种）**：

| 敌人 | 职责 |
|---|---|
| **Chaser** | 逼玩家移动 |
| **Bomber** | 制造空间压力 |
| **Sniper** | 逼玩家观察预警 |
| **Sprayer** | 制造弹幕海 |

四类组合 = "割草 + 弹幕"的基本战场。

**WaveManager 数据驱动**（.tres 纪律，不写死在代码）：

```text
WaveConfig
├── SpawnDelay
├── EnemyKind
├── Count
├── Position
├── Formation
└── Elite
```

```text
Wave 01  Chaser × 6
Wave 02  Chaser × 4  Bomber × 2
Wave 03  Sniper × 2  Sprayer × 3
Wave 04  Elite
```

为 Boss 前"关卡编排"打基础。

## 五、软辅助：星辉修正（世界观内机制）

**命名"星辉修正"**（不叫辅助瞄准）——世界观内的战斗机制。

玩家子弹进化链：
```text
基础 → 轻微追踪 → 更强追踪 → 击杀分裂 → 形成星轨
```

敌弹修正分层：
```text
普通弹 → 轻微软修正 → 特殊弹严格 → Boss 核心机制不修正
```

**玩家越来越强 = 整个"弹幕语言"发生变化**，而非伤害数字增长。

## 六、M2 一局（目标 5-8 分钟）

```text
出击 → 敌群 → 击杀 → 星之残片 → 升级 → 弹幕越来越华丽
→ 敌人种类增加 → 继续升级 → 精英敌人 → 最终 Boss
```

玩家感受：开局"一颗小星弹"，10 分钟后"卧槽我现在是什么东西"。

## 七、M3 衔接（Boss 不应是突然出现的新系统）

M2 已让玩家学会：低速 / 小范围躲避 / 软辅助 / 弹幕识别 / 敌人分类 / 升级构筑。
M3 只需**全部升级一个层级**：

| 层级 | 普通敌人 | Boss |
|---|---|---|
| 弹幕 | 一个模式 | 三个模式组合 |
| 升级 | 改变一点攻击 | 改变整个战场 |
