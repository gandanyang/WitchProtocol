## 1. 一句话定位

用 AI 时代个人开发能力，挑战二次元商业 Demo 的实验作品。

## 2. 世界观核心

- 时代：魔导时代，天穹污染
- 魔女系统：少女契约成为魔女，力量代价 = **记忆**——每次禁忌魔法失去一段人生：喜欢的食物 → 小时候的朋友 → 为什么想成为魔女
- 主题：记忆如何构成一个人 ↔ 记忆被剥夺时还剩什么（与归星物语「生活痕迹」是同一硬币两面）
- 主角黎歌（17 岁新人魔女，「星骸魔法」；秘密：她不是第一次成为魔女）
- 第一章 Boss：初代魔女阿斯特拉——失控的救世者，她认为"人类之所以痛苦，是因为拥有选择"，想让所有人进入永恒梦境（不是坏人）

## 3. 技术栈（拍板）

Godot 4.7.1 .NET 版 + **C#**（net8.0，硬性要求）+ ComfyUI（角色 LoRA 脸统一 + 特效/背景规范）+ 程序合成音效

## 4. Demo 范围（砍半版）

黎歌完整 + 绯月限定登场；1 大三阶段 Boss（记忆读取演出 = 情感峰值）+ 1 中 Boss；5-6 敌人；序章 15-20 分钟。
（MVP 开发计划进一步收缩为 8-12 分钟一局闭环，见 `docs/MVP开发计划-v0.1.md`）

## 5. 立项门

M1 手感达标（≥6/10）✕ 归星物语上架完成 → WP 正式立项
