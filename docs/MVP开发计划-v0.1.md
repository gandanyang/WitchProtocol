# 《Witch Protocol：魔女协议》MVP 开发计划 v0.1

> 状态：**开工契约**（2026-08-19 用户拍板：C# 硬性要求；BattleFramework 放弃）
> 依据：用户 MVP 规格（2026-08-19）
> 前置环境：Godot 4.7.1 .NET 版 + .NET SDK 8.0.424 + VS Code C# 扩展（均已就绪）
> 本计划替代《立项概念文档 v0.1》（已归档至 docs/archive/）

## 0. 一句话

**8-12 分钟一局的「割草 → Boss 弹幕」完整闭环，验证一件事：一个魔女飞起来、打怪、升级、放技能、打 Boss，到底爽不爽。**

## 1. MVP 目标与边界

| 做 | 不做 |
|---|---|
| 1 个魔女黎歌（做成"完全体"） | 多地图 / 多章节 / 多角色切换 |
| 5 波小怪 + 2 精英 + 1 Boss 三阶段 | 抽卡 / 复杂养成 / 商店 / 联机 |
| 12 个升级 + 三选一成长 | 长剧情（只留 30-60 秒引子）/ 大量装备 |

## 2. 一局闭环（= 完成标准）

```
出击 → 小怪波次×5 → 精英×2 → 短暂成长 → Boss 登场
     → 观察机制 → 处理机制 → 爽一波 → 被 Boss 击败 → 结算
```

完整验收 = 规格「二十三、完成标准」的玩家体验路径逐条跑通，且玩家**想再打一遍**。

## 3. 操作与生存

| 输入 | 动作 |
|---|---|
| WASD / 方向键 | 移动 |
| Shift | 低速模式（弹幕核心操作） |
| Space | 主动技能（星轨展开） |
| X | Bomb / 大招（星辰坠落） |

- HP = 3 点：普通擦碰 -1；Boss 小弹 -1、大攻击 -1~2、特殊机制可能直接濒死
- 核心仍是：躲弹幕 + 走位 + 输出

## 4. 被击中反馈（红线，不马虎）

**受击**：屏幕轻微震动 + 魔女闪白 + 音效 + 数帧无敌 + HUD 闪烁。
**死亡**：不是 Game Over —— 魔女失去控制缓慢坠落 → 镜头拉远 → Boss 仍漂浮在天空。

## 5. 敌人（6 种 + 2 精英）

| # | 敌人 | 教学目的 |
|---|---|---|
| ① | 基础飞行怪（直线接近，数量最多） | 熟悉操作 |
| ② | 自爆怪（高速冲脸 + 爆炸） | 走位压力 |
| ③ | 狙击怪（停下 → 红色锁定线 → 射击） | 观察能力 |
| ④ | 弹幕怪（不追人，制造弹幕） | 弹幕密度 |
| ⑤ | 坦克怪（血厚） | 持续输出 |
| ⑥ | 精英怪（波次限定，带特殊能力） | 威胁优先级 |

精英 A「猎犬」：快速追踪，三连射。
精英 B「棱晶」：悬停场地中央，持续环形弹幕，玩家必须绕着打。

## 6. XP 与升级（割草爽感的来源）

敌人死亡掉落**星之残片** → 吸收涨经验 → `LEVEL UP / 选择你的魔法` → **三选一**。

12 个升级：

| 升级 | 效果 | 升级 | 效果 |
|---|---|---|---|
| 火力 | 主武器 +1 | 星环 | 角色周围旋转攻击 |
| 星轨 | 增加追踪星弹 | 追星 | 产生追踪弹 |
| 穿透 | 穿透 +1 | 余辉 | 技能持续时间增加 |
| 爆裂 | 敌人死亡产生爆炸 | 共鸣 | 攻击命中叠层 |
| 引力 | 拾取范围增加 | 过载 | 低 HP 时攻击提升 |
| 速射 | 攻击频率提升 | 护盾 | 获得一次护盾 |

目标体验：3 分钟前"我就射几个星星" → 3 分钟后"卧槽"，变成**移动弹幕生产机器**。

## 7. 波次设计（5 波，各有主题，不是无脑刷怪）

| 波 | 内容 | 目的 |
|---|---|---|
| W1 | 基础怪 | 熟悉操作 |
| W2 | + 自爆怪 | 开始要求走位 |
| W3 | + 狙击怪 + 弹幕怪 | 第一次真正弹幕 |
| W4 | 混合，数量增加 | 压力 |
| W5 | 大型敌群 + 精英怪 | 爆发 |

## 8. Boss：初代魔女「阿斯特拉」

> 视觉概念：曾经拯救世界的第一代魔女，已失控。她不是坏人——她认为"人类之所以痛苦，是因为人类拥有选择"，想让所有人进入永恒的梦境。

| 阶段 | 触发 | 机制 |
|---|---|---|
| Phase 1 审判 | 开场 | 星落（魔法阵锁定 2s 后陨石砸下）/ 星之雨（小弹幕压力）/ 十字审判（四条激光旋转，找空隙） |
| 机制 1「星核」 | 75% HP | 生成 4 枚星核，必须攻击；不打掉 Boss 持续回血 → 玩家第一次意识到：**Boss 不是纯拼输出** |
| Phase 2 | 50% HP | 音乐/背景变化；Boss **释放玩家刚才用过的攻击**（如星环）→ "Boss 在学习玩家" |
| 终焉仪式 | 25% HP | 场地中央巨大魔法阵，无法直接攻击；出现 3 个核心限时打掉（失败 → Boss 必杀直接死亡） |
| 终焉·星界坠落 | 最终 | 无论如何进入最终阶段；全屏弹幕覆盖 + 巨大陨星 → **玩家最终被击中（MVP 要求被击败）** |

## 9. 死亡演出与结算

死亡：魔女喘息 → 攻击停止 → BGM 逐渐降低 → 黎歌"……还不够……" → 镜头慢慢拉远 → 天空裂缝扩大 → 黑屏。
结算：`DEFEATED` + 战斗时间 / 击败敌人 / 最高等级 / 获得星之残片 + **"她还活着。"** + 按钮「再次挑战」。

## 14. 开发纪律（从 BattleFramework 迁移，教训不重犯）

1. **写完 ≠ 验证过**：每个里程碑必须跑通、可玩
2. **git 基线先行**：M0 即 init + 首次提交；每完成一个可玩点就提交
3. **数值宪法**：W1 立 Balance 表（全部标 `[PLACEHOLDER·待 playtest]`），与代码同步
4. **反馈层前置**：W1 就必须有受击反馈（震屏/闪白/飘字/音效）
5. **数据驱动**：升级/敌人/技能走 Resource，新增内容不改战斗系统
